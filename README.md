## Features

- Responsive layout across all screen sizes
- Scroll-triggered "slide from top" animations via `IntersectionObserver`
- Project showcase with expandable card grid
- Integrated contact form powered by [Web3Forms](https://web3forms.com/)
- Parallax background sections
- Smooth navbar with mobile-friendly collapse

## Getting Started

### Prerequisites

- Node.js `^20.19.0` or `>=22.12.0`
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/DimaxKun/cps1-vue.git
cd cps1-vue

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```

Output is generated in the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```
